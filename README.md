## 🔬 Project Deep-Dives

### 1. Fresh Beats: Strategic Artist & User Engagement Audit
* **Business Challenge:** Maximize visibility and ROI for promotional artist partnerships while boosting conversion rates from free tiers to paid subscribers.
* **Methodology & Output:** Structured an analytical framework linking streaming behavior to commercial metrics. Authored actionable executive summaries identifying historical genre trends to optimize content recommendation engines and target high-propensity subscribers.

### 2. Manhattan Airbnb Investment Analysis
* **Business Challenge:** Guide a real estate investor toward high-ROI property acquisitions within the highly competitive Manhattan short-term rental market.
* **Methodology & Output:** Standardized raw geolocation data and resolved missing variables using custom logical blocks. Built comprehensive multi-tier pivot tables to isolate seasonal pricing matrices, determining that while 1-bedroom units dominate general demand, studio layouts optimize returns in high-density corporate hubs.

### 3. E-commerce Conversion & Cohort Analysis
* **Business Challenge:** Isolate exact customer drop-off bottlenecks within a multi-phase sales journey and quantify long-term user retention.
* **Methodology & Output:** Extracted and partitioned large-scale raw event logs using SQL. Constructed a 3-stage visual conversion funnel and built acquisition cohorts over normalized intervals (`DATEDIF` / `TEXT`) to measure recurring user lifecycle value and retention decay.

### 4. Superstore Operational Audit & Profitability Strategy
* **Business Challenge:** Conduct a full diagnostic corporate audit to counteract severe operational margin shrinkage and potential insolvency.
* **Methodology & Output:** Dissected regional operational losses across nested dimensions in Tableau. Built a predictive framework for marketing capital allocations, utilizing a 1/5 profit-to-ad-spend baseline to isolate maximum geographic and seasonal Return on Ad Spend (ROAS).

### 5. Root Cause Analysis & Executive Dashboard: Superstore Returns
* **Business Challenge:** Diagnose the operational and geographic root causes behind an unsustainable volume of product returns for executive review.
* **Methodology & Output:** Developed an analytical dashboard from concept to deployment. Transformed sparse data fields into binary logical metrics to analyze individual client and product risk. Constructed a sequential Tableau Story Arc mapping return patterns geographically and seasonally to deliver high-level corporate mitigation strategies.

### 6. Shopify App Ecosystem & Developer Performance Analysis
* **Business Challenge:** Evaluate marketplace indicators determining software success and track merchant response-rate efficiency.
* **Methodology & Output:** Implemented an enterprise-level relational model linking core app profiles to user review tables. Engineered weighted data metrics via DAX columns (`rating * (1 + helpful_count)`) to filter out low-validity feedback, generating filtered performance scorecards benchmarking top-tier application developers.
